# 📦 推箱子 (Sokoban)

经典推箱子网页游戏，10 个精心设计的关卡等你挑战！

## 🕹️ 操作

| 按键 | 功能 |
|------|------|
| **↑ ↓ ← →** 或 **W A S D** | 移动角色 |
| **Z** 或 **Ctrl+Z** | 撤销上一步 |
| **R** | 重置当前关卡 |
| **<** **>** | 切换上/下一关 |

## 🎯 游戏规则

1. 将所有的 **箱子** 推到 **红色目标点** 上
2. 箱子只能推不能拉，一次只能推一个
3. 不能把箱子推到墙上或另一个箱子上
4. 所有箱子归位即可过关

## ✨ 特性

- 🎨 精美的像素风格画面
- 📊 步数统计 & 最佳记录（localStorage 保存）
- ↩️ 无限撤销（最多 200 步）
- 📱 支持触屏滑动操作
- 🏆 10 个难度递增的关卡

## 🚀 快速开始

直接在浏览器中打开 `index.html` 即可开始游戏！

```bash
# 或者用任意 HTTP 服务器
python -m http.server 8000
# 访问 http://localhost:8000
```

## 🛠️ 技术栈

- 纯 HTML5 + CSS3 + JavaScript
- Canvas 2D 渲染
- 零依赖，单文件运行
